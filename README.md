## Цель работы

Построить корректный пайплайн предобработки смешанных данных: отдельно обработать числовые и категориальные признаки, заполнить пропуски, масштабировать числа и выполнить one-hot encoding без утечки информации из test.

## Что реализовано

- признаки разделены на числовые и категориальные;
- для `age` и `monthly_income` используется медианная импутация;
- для `experience_years` используется среднее;
- пропуски категорий сохраняются как `__MISSING__`;
- числовые данные масштабируются `StandardScaler`;
- категории кодируются `OneHotEncoder(handle_unknown="ignore")`;
- все ветки объединены через `ColumnTransformer`;
- `fit` выполняется только на train, к test применяется только `transform`;
- проверяется одинаковое число итоговых признаков train/test.

## Запуск

```bash
python pipeline.py
```

## Ключевой вывод

Предобработку нужно обучать только на тренировочной выборке. Если вычислять медианы, средние, параметры масштабирования или категории encoder по всему датасету, возникает data leakage и оценка модели становится завышенной.
